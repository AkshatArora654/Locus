# gene_tool

A lightweight command-line tool to detect target genes (e.g., *ompR*) across bacterial genome assemblies using custom or NCBI-derived datasets.

---

## 🚀 Features

- Build gene search databases from genome assemblies  
- Detect query genes across multiple genomes  
- Compatible with NCBI genome datasets  
- Simple CLI workflow
